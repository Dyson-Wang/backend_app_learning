# 11 · 运算符与表达式

## 这个例子讲什么

把 Go 的表达式语法集中过一遍：算术与整数除法、比较与逻辑、短路求值、优先级、位运算、复合赋值、整数溢出、显式类型转换，以及「没有三目运算符」时如何表达。

## 怎么跑

```bash
cd backend-roadmap/01-go
go run ./basics/11-operators-and-expressions
```

## 关键点

- **整数除法截断**，`-7/2 == -3` 向零取整；取模符号跟随被除数。要浮点结果必须先把操作数转成 `float64`。
- **短路求值有语言规范保证**：`false && f()` / `true || f()` 右侧一定不执行，本例用 `calls` 计数器实证为 0。
- **位运算**有 `& | ^ &^ << >>`，`&^` 是「按位清除（AND NOT）」；`0b1100` 是二进制字面量。
- **溢出是 wrap-around**：Go 整数运算按固定宽度二进制补码回绕，`uint8(255)+1==0`、`int8(127)+1==-128`，**不 panic、不抛异常**，这是与「自动扩容大整数」最不同的地方。
- **没有隐式类型提升**：`int + int64` 直接编译失败，必须显式 `T(x)`；`float->int` 是截断而非四舍五入。
- **没有 `?:` 三目**：惯用写法是 `if ... else`，或像本例用泛型 `iif[T any]` 把分支包成表达式。

## 和其他语言的差异

| 语言 | 溢出 | 三目 / 等价 | 除法与特殊运算符 |
|---|---|---|---|
| Go | 固定宽度回绕，不报错 | 无 `?:`，用 `if` 或泛型 `iif` | 整数 `/` 截断；`&^` 位清除 |
| Node.js | `Number` 是双精度浮点，整数超出 `2^53` 丢精度；`BigInt` 不溢出 | `cond ? a : b`、`??`、`**` | `/` 恒为浮点；`//` 不存在；`>>>` 无符号右移 |
| Python | 任意精度 `int`，**不会溢出** | `a if cond else b`、`:=` 海象运算符 | `//` 整除（向下取整）、`**` 幂、`and/or` |
| Java | 同样回绕，但 `Math.addExact` 可抛 `ArithmeticException` | 有 `?:` 三目 | `/` 截断；`>>>` 无符号右移 |
| Rust | debug 溢出 panic、release 回绕；`checked_add` / `wrapping_add` / `saturating_add` 显式选择 | `if` 本身就是表达式，可 `let x = if c {a} else {b};` | `/` 截断；无 `++` |

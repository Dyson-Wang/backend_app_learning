# 99 · 跨语言对照

这套库的**终点**，不是附加题。

`basics/` 和 `advanced/` 是按语言纵向组织的；这一层把它们横向串起来。学完 5 门语言后，你应该能回答的是「同一个问题在 5 种运行时里分别怎么解、为什么不同」，而不是「我会 5 种语法」。

## 怎么用

1. 打开 `scenario-matrix.md`，挑一个编号（例如 `A02 超时与重试`）
2. 依次打开 5 门语言的对应目录，读代码和 README
3. 把差异结论填进矩阵里那一行的「结论」列
4. 特别记录三件事：
   - **机制名**：Go `context` / Node `AbortSignal` / Python `asyncio.timeout` / Java `orTimeout` / Rust `tokio::time::timeout`
   - **失败方式**：编译期拦住 / 运行时 panic / 静默错误
   - **代价**：代码量、可读性、性能、心智负担

## 建议优先做的 5 组对照

| 主题 | 为什么值得先做 |
|---|---|
| `basics/04` 错误处理 | 显式 error vs 异常 vs `Result`，最能看出语言哲学 |
| `basics/09` 并发原语 | 五种并发模型第一次正面相遇 |
| `A02` 超时与取消 | 同一条原则在 5 种运行时里的落地形态 |
| `B02` 幂等 | 与语言几乎无关，能验证「哪些是后端常识而非语言特性」 |
| `C01` 连接池 | 资源模型差异（GC / 无 GC、协程 / 线程）暴露得最彻底 |

## 关键点

- **`&&` / `||` 短路**，`&` / `|` 用在布尔上不短路：示例用带副作用的 `side()` 计数器实证右边是否被执行。
- **整数除法 `7/3=2`**，要小数必须有一个操作数是浮点（`7.0/2=3.5`）。
- **复合赋值 `+=` 自带隐式窄化 cast**，所以 `byte b; b += 200;` 能编译，而 `b = b + 200` 不能。
- **整数溢出静默回绕**（补码），`Integer.MAX_VALUE + 1 == Integer.MIN_VALUE`，不抛异常；需要精确用 `Math.addExact` 或 `BigInteger`。
- `>>>` 是无符号右移（高位补 0），`>>` 是有符号右移（补符号位）。

## 和其他语言的差异

| 能力 | Java | Go | Node.js | Python | Rust |
|---|---|---|---|---|---|
| 短路 | `&&` / `\|\|` | `&&` / `\|\|` | `&&` / `\|\|`（返回操作数） | `and` / `or`（返回操作数） | `&&` / `\|\|` |
| 整除 | `/` 两 int 即整除 | 同 | `/` 恒为浮点 | `//` 整除，`/` 浮点 | 整型 `/` 整除 |
| 溢出 | 静默回绕 | 静默回绕 | Number 双精度 | 任意精度 | release 回绕 / debug panic / `checked_*` |
| 三元 | `? :` | 无（用 if） | `? :` | `x if c else y` | `if` 表达式 |
| 位运算 | `& \| ^ ~ << >> >>>` | `& \| ^ ^& << >>`（无 `>>>`，有 `&^`） | `& \| ^ ~ << >> >>>` | 同 Java | `& \| ^ ! << >>` |
